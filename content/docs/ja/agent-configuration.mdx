title: "Agent を設定"
description: "指示・モデル・ツール・Environment 設定を再利用します。"
---

Agent を開くと、ライブ Preview pane と並べて設定できます。

## 名前と説明

Name と description は任意の Agent プリセットを一覧や提供画面で識別するためのものです。実行状態は各 Session に属し、Agent タイプは選択しません。

## Runtime とモデル

最初に runtime を選択し、解決された Provider key で利用可能なモデルを選びます。モデル一覧が空の場合や runtime に **Needs key** と表示される場合は、現在の Project で対応する Provider を設定してください。

## System prompt

Agent の役割、境界、回答スタイル、確認が必要な条件を記述します。曖昧な personality の説明より、明示的な運用ルールを優先してください。公開前に正常系と失敗系の両方をテストします。

## Skill

現在の Project にある再利用可能な指示 package を添付します。Skill は新しい session に読み込まれ、タスクで必要なときに Agent が参照します。添付した Skill が見つからない場合、別の Project から流用されず missing として報告されます。

## MCP server

現在の Project にある認証済み Remote HTTPS MCP connection を添付します。connection は認証前でも添付できますが、tool を使用できるのは有効化と認証が完了した後だけです。

## Environment

package・setup script・変数・network policy を含む再利用可能な環境を選択します。未指定なら Project default を使い、新しい Session は選択した revision を固定します。Session 単位の実行では Full と Limited の両方を利用できます。[Environment のネットワークポリシー](/docs/ja/environments#network-policies)を参照してください。

## 保存と公開の動作

保存した編集はプリセットを使用する新しい Session に適用されます。既存 Session は受付時の設定を保持します。Publish は v1 などの公開済み設定を使うフローの live version を作成します。
