mosoo は選択した harness とモデルを永続 Session で実行します。Project キーから直接呼び出すか、再利用する設定を任意の Agent プリセットとして保存できます。

## 製品モデル

| リソース | 所有するもの |
| --- | --- |
| **Organization** | アカウントレベルのコンテナです。現在は単一オーナー向けであり、チームロールや招待は利用できません。 |
| **Project** | Agent、ファイル、設定、使用量を分離する境界です。新しいアカウントには Default Project が作成されます。 |
| **Agent** | runtime/model・指示・Skills・MCP 接続・Environment を含む任意の保存済みプリセット。 |
| **Thread / Session** | 受付時の設定・ネイティブ会話・分離された作業ファイル。続きの入力には同じ ID を使います。 |
| **Run** | Thread 内の一回の実行です。Run はイベント、ログ、使用量、ファイルを生成します。 |

## 一般的なワークフロー

1. Project を開き、モデルプロバイダーのアカウントを設定します。
2. Project キーを作成してバックエンドに保存します。
3. harness・モデル・指示を選び、Session を直接作成します。
4. 入力とファイルを送り、結果・イベント・artifact・利用量を確認します。
5. 非アクティブ期間やリソース回収後も、続きの作業には同じ Session ID を使います。
6. 設定を再利用する場合に Agent プリセットを保存します。v2 には公開は不要です。

<Callout type="info">
  ほとんどの設定は現在の Project に属します。Provider key、MCP credential、Skill、Environment は Project の境界を越えて自動的に共有されません。
</Callout>
