Project API key (`msp_`)で harness・モデル・指示を選び、入力とファイルを永続 Session に送ります。Agent は任意の再利用可能なプリセットです。Project に自身のモデルプロバイダー認証情報を設定します。

## 実行モデル

- **Project** は認証情報・Session・任意の Agent プリセット・利用量を管理します。
- **Harness** は Session のワークスペース内でモデルとツールを実行します。
- **Session** は受付時の設定・会話・作業ファイルを保持します。続きの入力には同じ公開 Thread ID を使います。
- **Run** は一つの実行ターンで、個別の結果・イベント・利用量を記録します。

Session ごとに実行状態を分離し、Assistant/Task タイプは選択しません。正式な Session は非アクティブであるだけでは失効しません。Cloud のデバッグ Preview には別の 30 日ルールがあります。

## 設定と運用

- [モデルプロバイダーの認証情報](/docs/ja/providers-and-models)を追加します。
- 必要に応じて [Agent 設定](/docs/ja/agent-configuration)、[Skills と MCP](/docs/ja/skills-and-mcp)、[Environment](/docs/ja/environments)を再利用します。
- [プリセットをテスト](/docs/ja/test-and-debug)し、[Run・ファイル・利用量](/docs/ja/operations)を確認します。
- [Project と Session の概念](/docs/ja/concepts)を参照してください。

## API バージョンと資料

新しい連携には [v2 API リファレンス](/docs/ja/api-reference-v2)を使います。公開済み Agent を使う既存の連携では、[v1 クイックスタート](/docs/ja/quickstart-v1)、[v1 リファレンス](/docs/ja/api-reference)、同じ Thread/Run ID を引き続き使用できます。Publish が必要なのは公開済み設定を選ぶフローだけです。

対象環境が記載の v2 ルートを提供していることを確認してください。このリリースガイドは Cloud 本番への提供を保証しません。Project API key (`msp_`)はバックエンドに保持し、アプリケーション利用者の認証はバックエンドが行います。

[ソース](https://github.com/langgenius/mosoo)、[llms.txt](/docs/llms.txt)、[llms-full.txt](/docs/llms-full.txt)から実装とドキュメント索引を参照できます。

現在の v1 契約は [OpenAPI](https://cloud.mosoo.ai/api/v1/openapi.json) で確認できます。
