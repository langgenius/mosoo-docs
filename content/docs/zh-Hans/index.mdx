## 执行模型

- **Project** 拥有模型凭据、Session、可选的 Agent 预设和用量记录。
- **Harness** 在 Session 工作区内调用模型和工具。
- **Session** 保存接纳时的配置、会话和工作文件。后续输入沿用同一个公开 Thread ID。
- **Run** 表示一次执行轮次，记录独立的结果、事件和用量。

每个 Session 拥有独立执行状态，不再选择 Assistant/Task 类型。正式会话不会因为闲置到期；Cloud 调试 Preview 使用单独的 30 天闲置策略。

## API 版本与资料

新接入使用 [v2 API 参考](/docs/zh-Hans/api-reference-v2)。已有发布型 Agent 集成保留 [v1 快速开始](/docs/zh-Hans/quickstart-v1)、[v1 参考](/docs/zh-Hans/api-reference) 及原 Thread/Run ID。只有选择已发布配置的流程需要 Publish。

请确认目标部署支持所述 v2 接口；本发布指南不代表 Cloud 生产环境已提供这些能力。Project API key (`msp_`) 应保存在后端，由后端验证你的应用用户。

[源码仓库](https://github.com/langgenius/mosoo)、[llms.txt](/docs/llms.txt) 和 [llms-full.txt](/docs/llms-full.txt) 提供实现与文档索引。

已部署的 v1 契约可通过 [OpenAPI](https://cloud.mosoo.ai/api/v1/openapi.json) 查看。
