title: "配置 Agent"
description: "保存可复用的指令、模型、工具和 Environment 配置。"

打开 Agent 后，可以在同一个工作区中编辑配置并即时 Preview。

## 身份

Name 与 description 用于在列表和交付入口中识别可选的 Agent 预设。执行状态属于各个 Session，不再选择 Agent 类型。

## 运行时与模型

先选择 runtime，再选择其 Provider key 可用的模型。如果模型列表为空或 runtime 显示 **Needs key**，请在当前 Project 中配置对应 Provider。

## 系统提示词

明确描述 Agent 的角色、边界、回答风格，以及何时应该追问。相比模糊的人设文案，应优先写清可执行规则。发布前同时测试正常与失败路径。

## 技能

从当前 Project 绑定可复用的指令包。新 session 会获得这些 Skills，Agent 在任务需要时读取。若 Skill 缺失，mosoo 会报告问题，而不会从其他 Project 借用。

## MCP 服务器

绑定当前 Project 中已授权的 Remote HTTPS MCP 连接。未授权时也可以先绑定，但只有启用且授权完成的连接才能在 Run 中提供工具。

## 环境

选择用于 packages、setup script、variables 和网络策略的可复用环境模板。未显式选择时使用 Project default，新 Session 固定选中的版本。Full 和 Limited 均适用于 Session 独立执行，详见 [Environment 网络策略](/docs/zh-Hans/environments#network-policies)。

## 保存与发布

保存后的修改用于新建的预设 Session，已有 Session 保持接纳时的配置。Publish 为 v1 及其他发布型交付流程创建 live 版本。
