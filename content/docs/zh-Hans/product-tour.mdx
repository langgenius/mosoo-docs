---

mosoo 在持久 Session 中运行选定的 harness 和模型。你可以通过 Project key 直接调用，也可以按需把复用配置保存为 Agent 预设。

## 产品模型

| 资源 | 负责的范围 |
| --- | --- |
| **Organization** | 账号级容器。当前产品是单所有者体验，暂不提供团队角色和邀请。 |
| **Project** | Agent、文件、配置和用量的隔离边界。新账号会获得 Default Project。 |
| **Agent** | 可选的已保存预设，包含 runtime/model、指令、Skills、MCP 连接和 Environment。 |
| **Thread / Session** | 接纳时的配置、原生会话与独立工作文件，后续输入沿用同一个 ID。 |
| **Run** | Thread 中的一次执行，会产生事件、日志、用量和文件。 |

## 典型工作流

1. 打开 Project 并配置模型账号。
2. 创建 Project key 并保存在后端。
3. 选择 harness、模型与指令，直接创建 Session。
4. 发送输入和文件，查看结果、事件、产物与用量。
5. 闲置或资源回收后，相关工作沿用同一个 Session ID。
6. 需要复用配置时保存 Agent 预设；v2 不要求发布。

<Callout type="info">
  大部分配置属于当前 Project。Provider key、MCP 凭据、Skill 和 Environment 不会自动跨 Project 共享。
</Callout>
