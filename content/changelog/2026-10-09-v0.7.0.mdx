An Alpha release focused on repository simplification and sandbox operations.

### Improvements and fixes

- Remove dead code, retired Pet/Cattle and App Deployment paths, per-turn budget residue, duplicate validation, and unmeasured caches and retries. Product and engineering documentation is consolidated.
- Bound container lifetime and capacity failures, and extend operational monitoring to every sandbox container application.
- Public Thread API v1/v2 wire contracts remain unchanged. This release adds no D1 migration or database DDL; the production schema remains at migration 0018.

### CLI compatibility

The internal console GraphQL schema removes operations and fields selected by older CLI builds, including `startAgentRun`, `sessionMessages`, `controlPlaneOverview`, `organizationBillingCostCard`, and `createEnvironmentFork`. CLI builds consuming these fields require a regenerated contract and matching release. The versioned public Thread API is unaffected.

### Release verification

The release notes record a production deployment at `dadfb757b2`, with API and Web Workers redeployed, all five sandbox images rebuilt, and the maintenance cron verified. Targeted staging acceptance covered the OpenAI, OpenCode, Pi, and DeepSeek paths, direct v2 Sessions, usage, idempotency, cancellation, and model-availability admission.

### Version numbering

The preceding Host release was corrected from v0.6.0 to [v0.5.1](https://github.com/langgenius/mosoo/releases/tag/v0.5.1), while its original Git tag was retained. This explains the gap in the published release list; v0.6.0 is not a missing intermediate feature release.
